# Changelog

## 0.1.0 — 2026-10-19

First public release of Quotient, a plain-text desktop calculator.

- Inline results for calculations written one per line.
- Unit conversions, percentages, complex numbers and high-precision math.
- Variables, user-defined functions, matrices, statistics and financial functions.
- Syntax highlighting, autocomplete and searchable built-in help.
- Light and dark themes, automatic saving, file import/export and click-to-copy results.
- Full display of wrapped and multiline results without overlapping later lines.
- A custom application icon and Linux launcher integration.
- A strictly confined x86-64 Snap with automated build, calculation and desktop startup checks.

The initial Snap testing release passed automated checks on Ubuntu 24.04 and
desktop acceptance checks on Fedora 44 before promotion to stable. macOS and
Windows builds have not been verified for this release.
